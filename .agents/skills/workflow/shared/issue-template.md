# Issue template

Adapt headings to project language.

## Minimal

```markdown
## Context
What exists and why change is needed.

## Goal
1. …

## Acceptance criteria
- [ ] …

## Out of scope
- …

## Depends on
None.

## Related
- #N
```

## Feature (data / API / UI)

Add between **Goal** and **Acceptance criteria** as needed:

- **Schema / data model**
- **API**
- **UI**
- **Tests**

## Chore / policy

- **Changes** — numbered list
- **Policy** — one paragraph for the team after merge
